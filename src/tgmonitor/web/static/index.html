Grupos

    Regras

    Uma mensagem gera alerta quando casa com algum termo de inclusão e com nenhum de exclusão.

    Nova regra

    Termos simples casam por palavra inteira, sem acento e sem diferenciar maiúsculas: fe não casa com “feito”. Para regex, use barras: /s2[56]\s*ultra/.

    Situação
    Testar este rascunho

      Testar
